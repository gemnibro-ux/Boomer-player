# Boomer - псевдо4D плеер
## Что такое Boomer?
Boomer - это псевдо4D плеер воспроизводящий сложные 3D-анимации (которые сильно напоминают на псевдо4D) и всякие четырёхмерные (трёхмерные) модели. Он также **СКОРО** будет иметь свой
4D-редактор. На нём можно создавать 4D-модели и также улучшится воспроизведение моделей и 3D-анимации. 

##Бумерские признаки:
  - Простой и понятный дизайн 👠
  - Нифига себе кнопка паузы (стоп, кадр!) 🛑
  - И красующая надпись 0.1v
